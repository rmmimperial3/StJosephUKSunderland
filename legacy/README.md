# Legacy 2017 project

This folder holds the original `StJosephChurch` Maven / Eclipse tree from 2017.

It is a Selenium and TestNG suite (valid and invalid login, product creation, and hyperlink checks). The tests load a billing site at `stgeorgechurchperumbavoor.com/billing/`. They are not the public website for St Joseph's, Millfield, Sunderland, and they do not contain that parish's Mass times, clergy list, or address.

The tree is kept here so the old work is not deleted. The current parish site lives at the repository root.
